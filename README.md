# Airline Database Project

**Разработка реляционной базы данных и аналитика авиаперевозок**

## О проекте

**Airline Database Project** — учебный командный проект по разработке реляционной базы данных для предметной области «Авиаперевозки».

Цель проекта — создать структурированную базу данных для хранения информации о пассажирах, документах, аэропортах, рейсах, билетах и багаже, а также использовать SQL для анализа данных и получения практических выводов о работе авиаперевозок.

В рамках проекта была разработана структура базы данных SQLite, выполнена загрузка и проверка данных, подготовлены аналитические SQL-запросы и проведено исследование показателей авиаперевозок.

## Цели и задачи проекта

Основные задачи проекта:

- Изучить и подготовить исходный набор данных.
- Разработать структуру реляционной базы данных.
- Определить таблицы, атрибуты и связи между сущностями.
- Создать таблицы и заполнить их данными с помощью SQL.
- Проверить качество данных и выявить возможные ошибки.
- Разработать аналитические SQL-запросы.
- Исследовать спрос, выручку и багажную нагрузку по направлениям.
- Сформировать итоговый аналитический отчет с выводами.

## Структура базы данных

База данных состоит из шести взаимосвязанных таблиц:

| Таблица      | Назначение                                |
| ------------ | ----------------------------------------- |
| `passengers` | Информация о пассажирах                   |
| `documents`  | Документы пассажиров                      |
| `airports`   | Сведения об аэропортах                    |
| `flights`    | Информация о рейсах и направлениях        |
| `tickets`    | Данные о билетах, их стоимости и статусах |
| `baggage`    | Информация о багаже и его весе            |

Связи между таблицами позволяют объединять информацию о пассажирах, рейсах, билетах и багаже для проведения комплексного анализа.

## Проверка качества данных

Перед проведением аналитики была выполнена проверка качества данных.

Проверялись следующие показатели:

- Пропуски в данных пассажиров и аэропортов.
- Дубликаты номеров документов.
- Повторяющиеся места на одном рейсе.
- Подозрительные значения возраста пассажиров.
- Некорректные значения стоимости билетов.
- Подозрительный вес багажа.
- Нарушения внешних ключей.
- Документы без соответствующих пассажиров.
- Багаж без связанных билетов.

**Выявленная проблема:** у 8 аэропортов назначения отсутствуют сведения о стране и коде страны. Эти значения сохранены как `NULL`, поскольку соответствующая информация отсутствует в исходном наборе данных.

## Аналитическое исследование

Для исследования авиаперевозок были сформулированы три основных аналитических вопроса.

### 1. Спрос и выручка по направлениям

**Вопрос:** Какие направления авиаперелетов пользуются наибольшим спросом и приносят наибольшую выручку?

В рамках исследования анализировались:

- Количество проданных билетов по направлениям.
- Общая выручка.
- Средняя стоимость билета.
- Минимальная и максимальная стоимость билетов.

### 2. Багажная нагрузка по направлениям

**Вопрос:** На каких направлениях перевозится наибольший суммарный вес багажа и каков средний вес одной единицы багажа?

Исследование включало:

- Количество единиц багажа.
- Общий вес багажа по направлениям.
- Средний вес одной единицы багажа.
- Минимальный и максимальный вес багажа.

### 3. Комплексный анализ направлений

**Вопрос:** Как соотносятся спрос, выручка и багажная нагрузка на разных направлениях авиаперевозок?

Заключительное исследование объединило результаты двух предыдущих запросов. Для каждого направления сопоставлялись количество проданных билетов, выручка, общий вес багажа и средний вес багажа в расчете на один билет.

Такой подход позволил оценить направления одновременно с коммерческой и операционной точек зрения.

## Основные результаты

### Спрос и выручка

- Проанализировано 8 направлений.
- Учтено 182 проданных билета.
- Общая выручка составила 6 349 489,21 ден. ед.
- Лидирующее направление — Böblingen Flugfeld — PHM.

Результаты лидирующего направления:

- 30 проданных билетов.
- Выручка — 1 046 136,20 ден. ед.
- Средняя стоимость билета — 34 871,21 ден. ед.

### Багаж

- Перевезено 163 единицы багажа.
- Общий вес составил 2 623,2 кг.
- Средний вес одной единицы багажа — 16,09 кг.

Лидирующее направление — Böblingen Flugfeld — PHM:

- 29 единиц багажа.
- Общий вес — 496 кг.
- Средний вес одной единицы — около 17,1 кг.

### Комплексный анализ

В рамках отдельной итоговой выборки получены следующие показатели:

- Количество билетов — 200.
- Общая выручка — 6 925 153,45 ден. ед.
- Общий вес багажа — 2 623,2 кг.
- Средний вес багажа на один билет — 14,41 кг.

Дополнительно сравнивалась багажная нагрузка на один билет по направлениям:

- Наибольшая — Zaraza Airport, 15,75 кг.
- Наименьшая — Ceres Airport, 9,85 кг.

## Ограничения исследования

При интерпретации результатов необходимо учитывать следующие ограничения:

- Анализ охватывает ограниченную выборку из 8 направлений.
- Для ряда аэропортов назначения отсутствуют сведения о стране и коде страны.
- В исходном наборе данных не указан период наблюдения, поэтому невозможно оценить сезонность.
- Отсутствуют сведения о расходах авиакомпании, поэтому исследование позволяет оценить выручку, но не прибыльность направлений.
- Выявленные различия между направлениями не позволяют однозначно установить причинно-следственные связи.
- В разных аналитических запросах использовались разные условия отбора данных, поэтому показатели количества билетов и выручки могут отличаться.

## Запуск проекта

Для работы с базой данных необходимо установить SQLite.

**1. Клонирование репозитория**

```bash
git clone https://github.com/your-username/project-name.git
cd project-name
```

**2. Проверка установки SQLite**

```bash
sqlite3 --version
```

**3. Создание базы данных**

```bash
sqlite3 airline.db < sal/schema.sql
```

**4. Заполнение таблиц**

```bash
sqlite3 airline.db < sal/insert_data.sql
```

**5. Проверка созданных таблиц**

```bash
sqlite3 airline.db
```

В консоли SQLite:

```sql
.tables
```

Должны отобразиться шесть таблиц:

```text
airports
baggage
documents
flights
passengers
tickets
```
